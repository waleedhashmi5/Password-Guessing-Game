# Password-Guessing-Game
A command-line Python game where users try to guess a randomly selected secret word based on difficulty level. The program provides hints after each incorrect guess, helping the user gradually reach the correct answer.

⸻

🚀 Features

* Multiple difficulty levels (Easy, Medium, Hard)
* Random word selection using Python’s random module
* Hint system showing correct letter positions
* Tracks number of attempts
* Interactive command-line gameplay

⸻

🛠️ Technologies Used

* Python
* Random module
* Loops and conditional statements

⸻

💡 How It Works

1. User selects a difficulty level
2. A random word is chosen from the corresponding list
3. User guesses the word
4. After each incorrect guess:
    * Correct letters in correct positions are shown
    * Remaining letters are hidden using _
5.The game continues until the correct word is guessed
